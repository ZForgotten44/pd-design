# Living Centennial — Cross-Platform Design

A **design system and web prototype** for an intergenerational, child-centered memory ecosystem: *100 Years Seen Through Small Eyes*.

## What’s in this repo

| Path | Description |
|------|-------------|
| **`design-system/`** | Design tokens (colors, typography, spacing), README |
| **`web/`** | Web prototype: sunrise hero, Living Parish Map, 1905→2025 timeline |
| **`cross-platform-spec.md`** | Full cross-platform brief: print, web, mobile, audio, optional AR |

## Run the web prototype

No build step. Open in a browser:

```bash
open web/index.html
```

Or serve locally (e.g. `npx serve web` or any static server) so fonts load reliably.

## Design vision

- **Three memory layers:** Children’s Voice (creative), Historical (archival), Living Community (interactive).
- **Platforms:** Print (book + QR), web (map + timeline), mobile (Memory Walk + GPS), audio (kids narrating).
- **Look & feel:** Cathedral stone, stained glass blues/reds/gold, sunrise warmth; serif + rounded sans; simple, emotional, not over-designed.

## Signature moment

The **homepage** is intended to feel like a soft sunrise hitting stained glass, with the line: *“This is our church.”* — in children’s voice.
