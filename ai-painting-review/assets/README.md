# Study image slots

The presentation never shows a generated substitute where a study image belongs. Each slot loads the file named below if it exists. Otherwise the frame shows a labelled placeholder that gives the exact figure needed and its source link.

**Two ways to fill a slot**
1. Copy the file here with the exact name and reload. This survives anywhere the folder goes, so it is the right choice for recording.
2. Drag an image file onto the frame in the browser. It is stored in that browser's local storage for this file only. Alt-click the frame to clear it.

Once a slot is filled, check sharpness at 1920×1080 fullscreen. If the only available copy is small or blurry, leave the placeholder in place. The brief says to give an exact placeholder rather than show a blurred image.

The opening and closing painting is **not** a study image. Seeded code draws it live, and it carries an on-screen label saying so.
